# Testes de processamento de documentos

Disponibilizar cópias locais dos documentos enviados pelo professor e criar testes do backend para documentos de questões e de base de conhecimento, com texto nativo e com necessidade de OCR.

- AC-001: baixar os PDFs desse professor, preservando nomes e conteúdo, em pasta local identificável sem incluí-los inadvertidamente no Git.
- AC-002: cobrir os quatro cenários com testes repetíveis, identificando explicitamente dados simulados e dependências opcionais.
- AC-003: executar os testes disponíveis, revisar os resultados e apresentar erros e limitações.
- Não modificar registros do banco nem iniciar reprocessamento real como parte dos testes.
