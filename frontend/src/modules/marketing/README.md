# Módulo marketing

Responsável pela landing page institucional do MeuMonitor AI.

Público principal:

- professores que desejam criar um produto digital recorrente.

Rota principal:

- `/`

## API pública e convenções

Componentes visuais usam `PascalCase`; hooks usam `camelCase` com prefixo `use`; serviços usam `camelCase` com sufixo `Service`; tipos usam `PascalCase`. A página importa componentes pesados por import dinâmico explícito.
